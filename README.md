# 프러쉬(Frush) - AI 영상 광고 제작 스튜디오

기업, 공공기관, 프랜차이즈를 위한 AI 영상 광고 제작 솔루션 홈페이지입니다.

- **사이트**: [www.myfrush.com](https://www.myfrush.com)
- **기술**: HTML, Tailwind CSS, Chart.js, AOS, Web3Forms

## 프로젝트 구조

```
├── index.html          # 메인 홈페이지
├── Images/             # 로고 및 이미지 에셋
├── Videos/             # 포트폴리오 영상
├── Image_Storage/      # 블로그/SNS용 이미지 저장소
├── CNAME               # GitHub Pages 커스텀 도메인
├── sitemap.xml         # SEO 사이트맵
├── robots.txt          # SEO 로봇 설정
└── .gitignore
```
