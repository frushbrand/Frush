## 성능 최적화

- **영상 Lazy Loading**: Intersection Observer API를 사용하여 뷰포트에 진입할 때만 영상 재생, 벗어나면 일시정지
- **preload="none"**: 히어로 영상 외 모든 영상은 초기 로드 시 데이터를 다운로드하지 않음
- **히어로 영상**: `preload="metadata"`로 최소한의 메타데이터만 미리 로드

## 상담 폼 (Web3Forms)

- **서비스**: [Web3Forms](https://web3forms.com) (무료 250건/월)
- **방식**: 클라이언트 사이드 fetch API로 비동기 전송
- **특징**: 즉시 이메일 전송, 페이지 새로고침 없이 성공/실패 피드백, 스팸 봇 방지 honeypot 필드 포함

## 배포

GitHub Pages를 통해 자동 배포됩니다.

1. `main` 또는 `master` 브랜치에 push
2. GitHub Pages가 자동으로 빌드 및 배포
3. CNAME 파일에 의해 `www.myfrush.com`으로 커스텀 도메인 연결
